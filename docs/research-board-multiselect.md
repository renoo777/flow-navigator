# 调研：画板/画布类产品「多选 + 复制」的按键交互

> 目的：解决 Flow Navigator 里「用鼠标/触控板选中多个节点再复制」的交互设计。
> 调研对象：以飞书画板为主要参照 → 对照 Figma（行业标杆）与 Flow Navigator 现状。
> 日期：2026-09-06 · 方法：产品调研（pm-skills competitor-analysis 框架简化版），信息源为各产品官方帮助中心。

## 一、飞书画板：官方按键操作全景

（来源：飞书帮助中心《编辑画板》《调整画板基础配置》 + 飞书官方 wiki《在页面画布中复制组件》）

| 操作 | 飞书画板按键方式 |
|---|---|
| 选中单个 | 单击元素 |
| **框选多个** | **左键按住拖拽画框**（默认触碰即选中；开启「精准框选」后只选被完整框住的元素） |
| 加选多个 | **Ctrl/⌘ + 单击**（不连续）；**Shift + 单击/拖**（区间连续） |
| 全选 | Ctrl/⌘ + A |
| 复制 / 粘贴 | 多选后 **Ctrl/⌘ + C** → **Ctrl/⌘ + V**（另有 Ctrl+Shift+V = 携带依赖粘贴、工具栏复制图标） |
| 移动画布 | **右键拖** / **空格+左键拖** / 右下角「小手」或 **H 键**进入移动模式再拖（平移不占用左键框选手势） |
| 缩放 | **Ctrl/⌘ + 滚轮**；右下角 ± / 缩放至 100% / 全览 |
| 微调移动 | 选中后方向键移动；Shift+拖元素 = 水平/垂直约束 |
| 删除 | Delete（多选后同样生效） |

**要点**：飞书画板是「画板」定位——**左键拖 = 框选**，画布移动全部交给右键/空格/H/双指，二者互不打架；多选后 Ctrl+C/V 即成组复制。

## 二、行业对照（左键拖 = 框选是画布类产品的事实标准）

| 能力 | 飞书画板 | Figma | Miro / draw.io 等 | **Flow Navigator（当前 v0.1.2）** |
|---|---|---|---|---|
| 空白左键拖动 | **框选多个** | **框选多个**（Move 工具） | **框选多个** | ❌ 被用作「平移画布」 |
| 平移画布 | 右键拖 / 空格+拖 / H | 空格+拖 / H 抓手 / 中键 | 空格+拖 / 右键 / 双指 | 空白左键拖 |
| 多选补充 | Ctrl/Shift+单击、Ctrl+A | Shift+单击、Ctrl+A | Shift+单击、Ctrl+A | Shift/Ctrl+单击、Ctrl+A |
| 复制粘贴 | Ctrl+C/V（+Shift+V 带依赖） | Ctrl+C/V、Ctrl+D、Alt+拖复制 | Ctrl+C/V | ✅ 已有（Ctrl+C/V，连边关系保留） |
| 滚动 | 滚轮/触控板双指 | 触控板双指 / 滚轮 | 双指 / 滚轮 | ✅ 滚轮/双指=滚动 |
| 缩放 | Ctrl+滚轮 | Ctrl+滚轮 / 捏合 | Ctrl+滚轮 / 捏合 | ✅ Ctrl+滚轮 / 捏合 |

## 三、差异根因

上一轮（v0.1.2）按「单击拖动移动页面」的诉求，把**空白左键拖 = 平移**，代价是**丢了拖拽框选**——当前多选只能逐个 Ctrl+单击，节点一多就费劲；这正是你问「怎么用鼠标多选复制」的原因。
而调研的所有主流画板（飞书/Figma/Miro/draw.io）**无一例外用左键拖做框选**，平移交给空格/右键/H/双指——「框选」是画布类产品最基础的多选手势，不该让位给平移。

## 四、方案选项

| 方案 | 交互形态 | 优点 | 缺点 |
|---|---|---|---|
| **A · 回归主流画板模型**（推荐） | 左键拖空白 = 框选；平移改 **空格+拖 / 右键拖 / H 抓手**；触控板双指滚动、Ctrl+滚轮缩放不变 | 与飞书/Figma 完全一致，框选→Ctrl+C/V 多选复制一步到位；用户零学习成本 | 与上一版手感相反，需重新适应「移动用空格/右键」 |
| **B · 保留平移，Shift+左拖 = 框选** | 左键拖 = 平移不变；**按住 Shift 左键拖 = 框选**（Shift+单击仍=加选，单击/拖两种手势不冲突） | 保留现有手感，改动最小 | 与主流不一致，框选须按修饰键，不够直觉 |
| **C · 工具模式切换** | 工具栏加「选择(框选)/抓手(平移)」切换，快捷键 V / H | 两种模式都完整，飞书同款 H 抓手 | 多一步切换，初学者略绕 |

> 说明：A 里「H 抓手」可做成可选项——保持默认右键/空格平移即可，抓手模式不强求。
